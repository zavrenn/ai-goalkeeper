# Local video

Place your local video here as `penalties.mp4`, or set `VIDEO_PATH` in `.env.local` to an existing file. Video files are ignored by Git.

The included annotations match the [Liverpool vs Chelsea shootout montage](https://www.youtube.com/watch?v=AfDNWqFiHJg), at its original 1280×720 resolution and timing. A different edit or video requires updated annotations in `data/penalties.json`.
